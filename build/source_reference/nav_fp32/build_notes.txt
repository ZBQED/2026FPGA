C++ ABI repair
  The existing GCC13 cross compiler was paired with GCC13 standard headers but
  the vendor library is libstdc++.so.6.0.27. GCC13 headers introduced an unresolved
  std::__throw_bad_array_new_length helper. We use the GCC9 ARM standard headers
  from Ubuntu's official cross development package with -nostdinc++, while
  continuing to link the original vendor library. No substitute runtime symbols
  were added. GCC13 recognizes __remove_cv as a builtin keyword, so the private
  template alias of that name in the extracted GCC9 unique_ptr header was renamed
  together with its two uses. cpp9_gcc13_keyword.patch records this type-alias-only
  change. This does not modify ABI or exception behavior.

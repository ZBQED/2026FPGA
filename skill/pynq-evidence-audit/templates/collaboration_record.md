# 大模型协作记录模板

用于整理真实对话，不允许补写虚构的历史提示词或回答。

| 字段 | 记录 |
|---|---|
| 原始对话导出路径/片段编号、SHA-256 | 待填写 |
| 记录ID、模型名称/版本、工具环境 | 待填写 |
| 用户提示词 | 从原始记录摘录，标明删节/脱敏 |
| 模型建议/代码 | 从原始记录摘录 |
| 失败、日志、误判 | 写明输入与观察，不只写“调试后成功” |
| 自我纠错/用户纠正 | 指向真实轮次 |
| 采纳改动、未采纳理由 | 待填写 |
| 验证命令与原始结果 | 待填写 |
| 通用技能、适用与失效条件 | 指向M01-M08/F01-F15或新条目 |

新提炼提示词标为“后续复用模板”，不能冒充历史原话。

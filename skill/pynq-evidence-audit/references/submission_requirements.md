# 技能包要求对照

适用条款为AMD自主选题部分的通用PYNQ技能及技能包要求，不将其他赛题或完整作品要求误作为一个技能目录即可完成的事项。

| 条款/要求 | 对应材料 | 验证或边界 |
|---|---|---|
| 3.3.2：面向PYNQ且可换题目、换板卡 | SKILL、参数化脚本、接口与多分支契约 | 以目标器件、时钟和接口契约配置参数 |
| 3.3.5.2：置于skill/，含README | skill/README.md | 安装入口、适用范围、用法和目录完整 |
| 每项说明适用场景、方法、失效条件 | README项目表、workflow | 指向各脚本/模板和错误处理 |
| 写明已验证效果 | validation与evidence | 提供板端摘录、离线示例、真实报告解析及复用模板 |
| 说明失败/观察来源 | failure_patterns、provenance、vision_pipeline | 每项标明触发、检查、修正和验证边界 |
| 校验脚本可复用 | 6类工具、统一入口、自检 | 黄金输出、资源时序、完整延迟、同帧融合及完整性 |
| 案例/模板可套用 | examples、templates、run_demo | 纯合成演示可执行；硬件专属输入需替换 |
| 提示词工作流 | prompts | 辅助复用模板；未给独立成功率，不作为已验证稳定工作流声称 |
| 踩坑清单 | failure_patterns | 条件、排查步骤和不可推断结论明确 |
| 3.3.5.3：提炼过程、验证与边界 | sources、validation、失败记录 | 本次Skill真实交互节选与纠错见development_record；完整作品交互与设计报告由参赛工程汇总，模板不替代原文 |
| 3.3.5.4：英文路径 | 全部交付路径 | README.md/SKILL.md按规范名称保留；正文可中文 |
| 工具版本与复现 | 环境记录、安装自检、文件指纹 | 记录工具版本；安装成功不等于Vivado从零重建成功 |
| 3.3.3.3：工程开源与再分发许可 | 发布仓库与许可文件属于提交方发布材料 | 附许可证、第三方归属与发布输入说明，按各文件的许可范围使用 |

完整作品还需RTL/HLS/PS源码、综合实现报告、上板计时、可复现构建及设计报告。技能目录只覆盖其对应提交范围，不代替这些材料。通用PYNQ加分由评审确定，不以目录完整或离线测试通过推定评分。

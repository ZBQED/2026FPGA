# 踩坑清单：触发、排查、修正、验证

F01-F09来自音频与资源核验记录，具体旧输入只作为历史排错对照，不是现用采集配置；板端测量摘录支持资源/服务检查，不独立证明全部音频事件。F10-F14来自工程接手与性能实验观察；F15来自官方资料和源码对照；F16-F18来自多板视觉流水的接口及验收要求。来源与内容指纹见sources和evidence/provenance.json。

| ID/触发条件 | 排查顺序与处理 | 验证/失效边界 |
|---|---|---|
| F01 已知兼容输入正常，目标音频输入失败 | 已知信号→采集数据→输入选择→接口接线/偏置→外设兼容；按原理图改接线/配置 | 换特定耳麦有效只证明该组合；不能推广为“三段都坏/四段都行” |
| F02 同SD换同型号板仍失败 | 核对共同软件、线材、配置、外设、供电选择，先修共同条件 | 重复症状不证明两板硬件绝对正常 |
| F03 后台持有音频/DMA，Notebook再初始化 | 先查现有服务和资源拥有者；只读核验不创建Overlay；主动实验需互斥及恢复 | 检查服务/PID/关键SHA前后；网灯亮不代表模型正常 |
| F04 历史文件名与当前输入不一致 | 启动参数→配置→代码→本轮日志，按当前事实修正文档 | 文件名linein不证明现在用LINE IN |
| F05 有音量无业务输出 | 分开检查采集、门限、推理、通信会话；用各阶段状态定位 | 无接收会话可能拦截发送，不等于模型坏；不擅删业务保护 |
| F06 PS跑模型但已加载BaseOverlay | 核对BIT/HWH来源，另取对应实现资源报告，分别写PS与PL | 未用某功能不等于它没有占PL；HWH实例数不是LUT数 |
| F07 待机采样与另起推理混在一起 | 按PID和窗口分别采样，记录并发背景、CPU单核/整机口径、RSS语义 | 不能把两进程总量称作生产单进程峰值；共享页不能直接当独占DDR |
| F08 同录音/固定输入重复一致 | 保留确定性结果，再用独立标签数据评质量、不同输入检缓存 | 重复10次一致不等于100%准确率 |
| F09 板端时钟不可信/日志有旧PID | 用运行ID、启动周期、PID与内容指纹绑定记录，耗时使用窗口内单调计数 | 不将不同启动周期或不同PID的结果混成一轮实验 |
| F10 仿真、算子一致、整网/业务混为一谈 | 对每层输出/整体数值/业务语义分别列验收，先找首个分歧 | 固定算子或C/RTL通过不能证明整网、现场语义、显示速度通过 |
| F11 device快但完整系统慢 | 同帧标记采集→预处理→传输/排队→核→后处理→显示；计调用数和字节，再改最大开销 | 原观察后端49.920s、驱动累计4.050s，差额约91.89%；只是该旧记录，不是现值。分项全消除也不能承诺整链达标 |
| F12 更多并行核/更高频仍不可部署 | 先查资源余量、带宽、共享缓冲和布线；优先复用/减少搬运，再验证质量和整链 | 既有报告BRAM139/140；不能盲目复制整核。预算与理论MAC下界不是计时 |
| F13 综合/C仿真成功但布局/RTL失败 | 保留具体阶段、版本和失败日志；C→RTL→综合/实现→实板逐项核验 | 项目曾有增量布局失败及RTL超时；不能只交成功截图，或用WNS掩盖hold/pulse/未约束项 |
| F14 ZIP哈希完整但接手跑不起来 | 检查绝对盘符、解释器、离线环境、设备ABI、恢复所需输入，修相对路径和依赖清单 | 清单通过只保证文件；从空环境构建/启动另记结果 |
| F15 DMA wait不结束/读到旧值/教程不符 | 驱动版本+HWH模式→TLAST/字节数/位宽/对齐→复位时钟→缓存同步；必要时用ILA | 教程与源码的SG支持存在差异；超时不释放仍被硬件使用的缓冲；本条采用固定提交源码核对 |
| F16 双区域或多板结果可能串帧 | 在每个结果保留原始帧、ROI帧、分支和原始输入SHA，汇合前用pipeline检查 | 离线反例已验证；角色标错但元数据伪装一致仍需业务核验 |
| F17 模型变体或预处理漂移 | 权重、预处理、输出约定分别哈希绑定，逐阶段比较黄金输出 | Lite/Full、输入尺寸或量化路径不能仅按名字替换；元数据匹配不等于数值匹配 |
| F18 新关键点接入旧时序分类器 | 验证点序、坐标基准、左右语义、可见性mask、采样间隔与真实标签质量 | 单帧关键点或分类通路有输出不等于现场语义通过；须独立质量验收 |

每个修正保留改前输入、改动、改后输出和失败边界；固定地址、口令、业务类别和专属分组不作为通用默认值。
